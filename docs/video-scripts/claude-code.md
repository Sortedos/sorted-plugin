# 60-second video: Sorted in Claude Code

Screens as checked on Windows 11 with Claude Code 2.1.291, 6 October 2026; the sign-in step itself was not filmed in that check. Fake company: Acme Trading.

| Shot | On screen | Spoken |
|---|---|---|
| 1 | The Sorted dashboard of Acme Trading | Here is Acme Trading's business, on one screen in Sorted. Now let's bring it into Claude Code. |
| 2 | `claude plugin marketplace add .` in the repository folder | Download this repository, open a terminal in its folder, and add it as a plugin source. |
| 3 | `claude plugin install sorted@sorted` and the success line | Then install the Sorted plugin. That brings thirteen skills and the connection to Sorted. |
| 4 | Claude Code with `/mcp`, choosing sorted, the browser sign-in page | Type slash M C P, choose Sorted, and sign in with your own Sorted account. No key to copy. |
| 5 | "Which numbers don't match between our systems?" and the answer with record links | Ask what does not match between your systems, for example your books and your bank, and get the exact records to fix, each with a link you can open. |
| 6 | "Add my Odoo receivables to Sorted" and the feed preview | When Sorted cannot reach a system, Claude can read it with read-only access and send the numbers. You approve a preview first. |
| 7 | The dashboard area with its label | It shows up on your dashboard, labelled honestly. Your assistant read these numbers; Sorted cannot check them. |
