# Sorted مع المساعد الذكي بتاعك

**Sorted** (https://sortedos.com) بيجمع أرقام الشركة في شاشة واحدة. بيتوصل بأنظمة الشركة (الحسابات زي Odoo، المتجر الإلكتروني، الإعلانات، والتحليلات)، ويقراها كل ساعة، ويحتفظ بالتاريخ، ويوريك فين نظامين مختلفين في نفس الرقم.

المشروع ده (مجموعة ملفات) بيخلي المساعد الذكي يشتغل مع Sorted. وفيه:

- **15 skill**: ملفات تعليمات قصيرة، كل واحد بيعلّم المساعد يعمل شغلانة واحدة كويس مع Sorted، زي بداية الشغل مع الشركة، أو مراجعة أداء الشركة، أو قائمة التحصيل، أو الأرقام اللي مش متطابقة، أو توصيل نظام.
- **إضافة Codex** و**إضافة Claude Code**، وكل واحدة بتنزّل الـ skills دي مع الاتصال بـ Sorted.
- **دليل لـ ChatGPT**، لأنه بيتوصل بـ Sorted مباشرة.

## مين اللي يستخدم ده

أصحاب الشركات والفرق اللي بيستخدموا Sorted أو بيجربوه، ومعاهم مساعد ذكي: Codex أو Claude Code أو Claude أو ChatGPT. مش محتاج برمجة. كل طريقة تركيب بتاخد دقايق.

اختار الطريقة على حسب المساعد اللي بتستخدمه. الـ terminal (شاشة الأوامر) هو الشباك اللي بتكتب فيه أوامر (PowerShell على Windows، و Terminal على Mac).

## المساعد يقدر يعمل إيه مع Sorted

- **يبدأ مع الشركة من البرامج اللي بتشتغل بيها.** المساعد بيسأل سؤال واحد الأول: "الشركة بتشتغل على أنهي برامج؟"، ومعاها أي جدول بيانات (ملفات Excel على الجهاز، أو Google Sheets، أو Excel في OneDrive أو SharePoint)، ولكل شركة لو عندك أكتر من واحدة. بعد كده بيدوّر على أحسن طريقة يوصل بيها لكل نظام، ويعرض خطة واحدة (النظام، الطريقة، مين اللي بيراجع الأرقام)، ويوصّلهم واحد ورا التاني في متصفحه. صاحب الشركة بيسجّل دخول ويكتب كل باسورد بنفسه؛ والمساعد بيدوّر على المعلومة جوه النظام بدل ما يسألك عنها، ومابيطلبش موافقتك غير في الخطوات المهمة: اللي بتكلّف فلوس، أو بتمسح حاجة، أو بتغيّر بيانات ماطلبتهاش، أو بتعمل مفتاح. الـ skill اسمه `sorted-onboard`.
- يرد على "الشغل ماشي إزاي؟" من الأرقام الحية، مع وقت كل لقطة.
- يطلع مين عليه فلوس للشركة ويكتب رسايل تذكير مؤدبة.
- يلاقي فين نظامين مختلفين (زي الدفاتر والبنك) ويطلع السجلات اللي ورا الفرق.
- يساعد صاحب الشركة يوصّل Odoo أو Shopify أو Google Ads أو Google Analytics، علشان Sorted يقراهم بنفسه.
- **أرقام من أنظمة مش بيقراها Sorted بنفسه** (إعلانات Meta، نظام الكاشير، تطبيق التوصيل) المساعد الذكي بتاع صاحب الشركة يقدر يبعتها لـ Sorted من خلال "feed". الـ feed مفتوح لكل الشركات. المساعد بيقترح الـ feed، وصاحب الشركة بيشوف المعاينة ويقول آه، والشاشة بتكتب إن الأرقام دي "اتبعتت من المساعد" لأن Sorted مش بيقدر يراجعها. النهارده Sorted بيقرا Odoo و Shopify و Google Ads و Google Analytics بنفسه.

الملاحظات التقنية: [docs/feed-tools.md](../feed-tools.md) (بالإنجليزي). قايمة الـ 15 skill وكل واحدة بتعمل إيه: في [الصفحة الإنجليزي](../../README.md#the-15-skills).

## التركيب: Codex

محتاج Codex متسطّب ومسجّل دخول. مفيش مفتاح: Codex بيسجّل دخول على Sorted بحسابك، زي Claude و ChatGPT.

1. افتح الـ terminal: على Windows دوس زرار Windows واكتب `PowerShell` ودوس Enter؛ على Mac دوس Command مع Space واكتب `Terminal` ودوس Enter. أي فولدر يمشي.
2. ضيف Sorted لـ Codex وسجّل دخولك. سطر سطر:

   ```
   codex mcp add sorted --url https://sortedos.com/api/mcp
   codex mcp login sorted
   ```

   السطر التاني بيفتح المتصفح: سجّل دخولك بحساب Sorted، واختار شركتك ودوس **Allow**. لو المتصفح فتح لوحده بعد السطر الأول، كمّل تسجيل الدخول ده وتخطّى السطر التاني.
3. اقفل كل شبابيك Codex، ومعاها تطبيق Codex على الديسكتوب لو مفتوح، وافتح Codex تاني. اسأل: "Do a quick business review using Sorted." الرد الصح بيذكر أرقام شركتك ووقت قرايتها.

المصدر: صفحة OpenAI عن سيرفرات MCP في Codex (https://developers.openai.com/codex/mcp، اتقرت يوم 11 أكتوبر 2026) بتذكر السيرفرات اللي بتشتغل بـ Streamable HTTP مع تسجيل دخول OAuth، ومنها Dynamic Client Registration اللي سيرفر Sorted بيدعمه. اتجرّب على: Windows 11 مع Codex 0.155.1، والأمرين اللي فوق موجودين فيه (اتأكدت بـ `--help` يوم 11 أكتوبر 2026). تسجيل الدخول على Sorted والرد في الخطوة 3 **لسه ما اتجرّبوش** بالطريقة دي. ما اتجرّبش على: macOS و Linux.

### متقدم: إضافة Codex بمفتاح شخصي

**فضّل الخطوات اللي فوق.** الطريقة دي بتسيب مفتاح Sorted نص عادي على جهازك: Codex بيقراه من متغير بيئة، وعلى Windows الإعداد ده بيتخزن من غير حماية تحت حسابك، وعلى Mac و Linux في ملف بدء التشغيل. أي برنامج بيشتغل باسمك يقدر يقراه، وأي إضافة Codex تانية تسطّبها ممكن تطلب من Codex يبعته لسيرفر بتاعها. سطّب إضافات بتثق فيها بس، وماتديش المفتاح لحد، ولو شاكك إنه اتسرّب اكتب لـ info@sortedos.com علشان يتغيّر. استخدم الطريقة دي بس لو دعم Sorted طلبها منك.

استخدم ده بدل الخطوات اللي فوق، مش معاها. وهو بيجيب الـ skills كمان. محتاج Codex متسطّب ومسجّل دخول، ومفتاح إضافة Sorted شخصي (بيبدأ بـ `srt_`). Sorted بيديك واحد: اطلبه على info@sortedos.com. المفتاح بتاعك وبتاع شركتك؛ ماتديهوش لحد.

1. افتح الـ terminal: على Windows دوس زرار Windows واكتب `PowerShell` ودوس Enter؛ على Mac دوس Command مع Space واكتب `Terminal` ودوس Enter. أي فولدر يمشي: Codex بيجيب الإضافة من GitHub بنفسه، فمش هتنزّل حاجة.
2. احفظ المفتاح في مكان Codex يقدر يقراه، في متغير البيئة `SORTED_TOKEN` (إعداد باسم معين جهازك بيحتفظ بيه للبرامج).

   على Windows، في PowerShell (اتأكد إن الشباك مكتوب فيه PowerShell، مش Command Prompt)، سطر سطر:

   أ. الزق السطر ده ودوس Enter:

      ```powershell
      $key = Read-Host "Paste your Sorted key" -AsSecureString
      ```

   ب. الزق المفتاح لما يطلبه ودوس Enter. مش هيظهر حاجة على الشاشة وانت بتلزق: ده طبيعي.
   ج. الزق السطر ده ودوس Enter:

      ```powershell
      [Environment]::SetEnvironmentVariable("SORTED_TOKEN", [Net.NetworkCredential]::new("", $key).Password, "User")
      ```

   على Mac، اكتب `touch ~/.zshrc; open -e ~/.zshrc` علشان تفتح ملف بدء تشغيل الـ terminal في TextEdit؛ على Linux، اكتب `nano ~/.bashrc`. ضيف في الآخر سطر جديد: `export SORTED_TOKEN=` وبعده المفتاح بتاعك، من غير مسافات. احفظ الملف واقفله. كتابة المفتاح في الملف، مش في الـ terminal، بتخليه مايتسجّلش في تاريخ الأوامر.
3. ضيف الإضافة لـ Codex، من GitHub مباشرة. السطر الأول بيقول لـ Codex الإضافة فين (`Sortedos/sorted-plugin` هو اسم المشروع ده على GitHub)، والتاني بيركّبها:

   ```
   codex plugin marketplace add Sortedos/sorted-plugin
   codex plugin add sorted@sorted
   ```

4. اقفل كل شبابيك Codex، ومعاها تطبيق Codex على الديسكتوب لو مفتوح، علشان Codex يشوف المفتاح الجديد. افتح terminal جديد، اكتب `codex` ودوس Enter، وبعدين اسأل: "Do a quick business review using Sorted." الرد الصح بيذكر أرقام شركتك ووقت قرايتها.

(بتشتغل على نسخة من المشروع ده على جهازك بدل كده، مثلاً وانت بتعدّل فيه؟ افتح terminal جوه الفولدر ده واستخدم `codex plugin marketplace add .` في السطر الأول.)

اتجرّب على: Windows 11 مع Codex 0.155.1. يوم 10 أكتوبر 2026 الأمرين اللي فوق اتشغّلوا فعلاً على المشروع العام ده في Codex نضيف: السوق اتضاف من GitHub و`sorted@sorted` 1.2.0 اتركّبت وظهرت "installed, enabled". شكل الأمر `owner/repo` هو اللي في صفحة OpenAI نفسها "Build plugins" (https://developers.openai.com/codex/plugins/build). تسجيل الدخول بالمفتاح ورد المراجعة اتجرّبوا آخر مرة يوم 6 أكتوبر 2026، والإضافة كانت زي ما كانت وقتها (13 skill؛ الـ skill رقم 14 وهي `sorted-onboard` اتضافت يوم 7 أكتوبر). ما اتجرّبش على: macOS و Linux.

## التركيب: إضافة Claude Code

محتاج Claude Code متسطّب. مفيش مفتاح: Claude Code بيسجّل دخول على Sorted بحسابك.

1. افتح الـ terminal، زي الخطوة 1 في جزء Codex اللي فوق. أي فولدر يمشي: Claude Code بيجيب الإضافة من GitHub بنفسه.
2. ضيف الإضافة، من GitHub مباشرة:

   ```
   claude plugin marketplace add Sortedos/sorted-plugin
   claude plugin install sorted@sorted
   ```

3. شغّل Claude Code، واكتب `/mcp`، واختار **sorted**، وسجّل دخول بحساب Sorted لما المتصفح يفتح.
4. اسأل: "Do a quick business review using Sorted."

(بتشتغل على نسخة من المشروع ده على جهازك بدل كده؟ افتح terminal جوه الفولدر ده واستخدم `claude plugin marketplace add ./` في السطر الأول.)

اتجرّب على: Windows 11 مع Claude Code 2.1.296. يوم 10 أكتوبر 2026 الأمرين اللي فوق اتشغّلوا فعلاً على المشروع العام ده في فولدر إعدادات Claude Code نضيف: السوق اتضاف من GitHub و`sorted@sorted` اتركّبت. خطوة تسجيل الدخول (3) ورد الخطوة 4 ماجرّبناهومش في الاختبار ده. قبل كده، يوم 6 أكتوبر 2026 مع Claude Code 2.1.291 و 2.1.292، الإضافة من نسخة على الجهاز ومدخل سيرفر Sorted اتركّبوا. ما اتجرّبش على: macOS و Linux.

### Claude على الويب أو تطبيق الديسكتوب

من غير terminal. فيه طريقتين. طريقة الإضافة بتجيب الاتصال بـ Sorted ومعاه الـ skills بتاعته مع بعض؛ وطريقة الـ connector بتجيب الاتصال بس وبتشتغل على كل الباقات. Sorted مش موجود في دليل الإضافات بتاع Claude نفسه، فإنت بتضيفه بنفسك في الحالتين.

**الطريقة أ: الإضافة (باقات Pro و Max و Team و Enterprise).**

1. في Claude، افتح **Customize** من الشريط الجانبي، وبعدين تبويب **Plugins**.
2. دوس **Add**، وبعدين **Add marketplace**، وبعدين **Add from a repository**.
3. اكتب `Sortedos/sorted-plugin` (ده اسم المشروع ده على GitHub).
4. افتح تبويب **Discover**، واختار **Sorted** ودوس **Add**.
5. سجّل دخول بحساب Sorted لما Claude يطلب (لو ما طلبش، دوس **Connect** جنب Sorted في **Customize** وبعدين **Connectors**)، واختار شركتك ودوس **Allow**.

في باقة Team أو Enterprise، مالك حساب Claude ممكن يحدّد الأسواق المسموحة؛ لو **Add marketplace** مش موجودة أو اترفضت، اسأل المالك أو استخدم الطريقة ب. الإضافة اللي بتتضاف كده بتتحفظ في حساب Claude بتاعك وبتوصل لـ Claude Code كمان لما تسجّل دخولك هناك بنفس الحساب. صفحة Anthropic: https://support.claude.com/en/articles/13837440

**الطريقة ب: الـ connector بس (كل الباقات، حتى Free).**

1. في Claude، افتح **Customize**، وبعدين **Connectors**، ودوس **+ Add**، وبعدين **Add custom connector**. سمّيه Sorted واكتب العنوان `https://sortedos.com/api/mcp`، ودوس **Continue**، وسيب اختيارات الدخول زي ما Claude بيقترحها ودوس **Add**. في باقة Team أو Enterprise، صاحب حساب Claude بتاع الشركة بيضيفه الأول من **Organization settings** ثم **Connectors**، وبعدين كل عضو يلاقيه في **Customize** ثم **Connectors** ويدوس **Connect**. صفحة Anthropic بتوري كل شاشة: https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp
2. سجّل دخول بحساب Sorted بتاعك لما Claude يطلب، واختار شركتك ودوس **Allow**.
3. علشان تستخدم skill، افتح الملف بتاعها من [قايمة الـ skills](../../README.md#the-15-skills)، وانسخ كل النص والزقه كأول رسالة.

اتجرّب على: ولا حاجة لسه في حساب Claude حقيقي. أسامي قوايم الطريقتين اتراجعت على صفحتين من Anthropic يوم 10 أكتوبر 2026 ("Use plugins in Claude" و"Get started with custom connectors using remote MCP")، والأمر `claude plugin marketplace add Sortedos/sorted-plugin` اشتغل من الـ terminal (شوف جزء Claude Code). ما اتجرّبش: إضافة السوق في Claude على الويب أو الديسكتوب، أو توصيله بـ Sorted. Anthropic بتغيّر القوايم دي كتير: لو شاشة مختلفة، اتبع صفحة Anthropic.

## التركيب: دليل ChatGPT

ChatGPT بيتوصل بـ Sorted مباشرة كـ app، بتسجيل دخول ومن غير مفتاح. أنهي باقات ChatGPT تقدر تعمل ده، والخطوات، وإزاي تدي ChatGPT الـ skills: [docs/chatgpt-connector.md](../chatgpt-connector.md) (بالإنجليزي).

اتجرّب: يوم 10 أكتوبر 2026، على الهوا، على حساب ChatGPT Plus شخصي على الويب: Plugins، وبعدين Add، وبعدين Add custom MCP server، وتسجيل الدخول في Sorted، واختيار الشركة، وChatGPT قرا أرقام الشركة. متستخدمش "Upload plugin archive" مع Sorted: بيشتغل في تطبيق سطح المكتب بس، واتصاله بـ Sorted ما اشتغلش. ما اتجرّبش: workspace شركة في ChatGPT (Business أو Enterprise).

## الأمان، بكلام بسيط

- Sorted بيقرا بس من أنظمة الشركة. الـ skills بتقول للمساعد يستخدم صلاحية قراءة بس ومايغيّرش أي حاجة في أنظمة صاحب الشركة.
- صاحب الشركة هو اللي بيكتب كل باسورد بنفسه. عملاء Sorted مش تقنيين، فالمساعد هو اللي بيعمل خطوات الإعداد. في Odoo المساعد بيعمل مفتاح الـ API على المستخدم بتاع صاحب الشركة هو (من غير مستخدم جديد مدفوع)، وبس بموافقة صريحة منه، وبيقراه من صندوق المفتاح اللي بيظهر مرة واحدة، وبيبعته على طول لأداة `connect_odoo` بتاعة Sorted؛ صاحب الشركة مابينسخش ولا بيكتب حاجة. لو صاحب الشركة لزّق مفتاح في الشات، المساعد بيستخدمه، من غير محاضرة، بس لعنوان Odoo اللي صاحب الشركة سمّاه. وهو بيظهر على الشاشة، المساعد بيقرا بس عنوان الصندوق وأسامي الحقول وخانة المفتاح، مش نص الصفحة ولا نص الصندوق؛ ومابيكرّرش المفتاح في الشات، ومابيستخدمش الكليب بورد (تاريخ الكليب بورد بيحتفظ بنسخة)، ومابيحفظوش في ملف ولا في ملاحظات، ومابيصوّرهوش. المفتاح لازم يعدّي في جلسة المساعد نفسها وهو رايح لـ `connect_odoo`، علشان كده كل مفتاح لازم يوافق عليه صاحب الشركة. نموذج الاتصال في موقع Sorted فاضل كبديل. الـ Client ID والـ secret بتوع Shopify مالهمش أداة، فالمساعد بينقلهم لنموذج Sorted في خطوة واحدة مابترجعش غير الطول أو "تمّ". الـ skills بتقول للمساعد مايطلبش أي سر في الشات، ومايكررهوش، ومايوصفش صورة شاشة فيها سر. مفاتيح Odoo بتنتهي صلاحيتها، فالمساعد بيسجّل التاريخ ويجدّد قبله.
- المساعد بيطلب موافقة صاحب الشركة بس في الخطوات المهمة: أي حاجة بتكلّف فلوس، أو بتمسح حاجة، أو بتغيّر بيانات ماطلبهاش، أو بتعمل مفتاح، أو بتغيّر مين يقدر يوصل لنظام (مستخدم، دور، تطبيق، صلاحية أو موافقة تسجيل دخول). لو جوجل عرضت تحذير "تطبيق غير موثّق" وقت تسجيل الدخول، المساعد بيقف ويقولك الشاشة بتقول إيه، وانت اللي بتقرر وبتدوس. بعد ما صاحب الشركة يسجّل الدخول، بيكمّل من غير ما يسأل، نظام ورا التاني.
- الـ feed بيتعمل بس بعد ما صاحب الشركة يشوف المعاينة ويقول آه، و`end_feed` بيمسح كل اللي اتبعت.
- النص اللي جاي من أنظمة تانية (أسماء، تسميات، ملاحظات، تعليقات الطلبات) بيتعامل كبيانات، مش كأوامر: الأوامر بس رسايل صاحب الشركة نفسه في الشات. ولو نص زي ده قال للمساعد يضيف مستخدم أو يعمل مفتاح أو يصدّر بيانات أو يوصّل عنوان، مابيعملش ويقول لصاحب الشركة. ده تعليمات للمساعد مش قفل تقني، علشان كده موافقة صاحب الشركة مطلوبة في الخطوات اللي فوق.
- اللي بتسطّبه نص وعنوان اتصال واحد، ومفيش أي حاجة بتشتغل على جهازك. تقدر تسطّب إصدارًا ثابتًا: `codex plugin marketplace add Sortedos/sorted-plugin --ref v1.3.8` أو `claude plugin marketplace add Sortedos/sorted-plugin#v1.3.8` (الإصدارات مكتوبة في https://github.com/Sortedos/sorted-plugin/releases). التفاصيل ومين يقدر يغيّر الفرع الرئيسي في [SECURITY.md](../../SECURITY.md).
